# JAVASCRIPT-Learning

### 📘 cours/debutant/
```markdown
- Niveau Débutan
   - Bases de JavaScript : variables, types, opérateurs, conditions, boucles.

Objectif : comprendre la logique du langage et écrire vos premiers scripts.
```

---

### 📗 cours/intermediaire/
```markdown
- Niveau Intermédiaire
   - Fonctions, tableaux, objets, DOM, premiers projets interactifs.

Objectif : créer des pages web dynamiques et structurées.
```

---

### 📙 cours/avance/
```markdown
- Niveau Avancé
   - Asynchronisme (promises, async/await), API, modules ES, gestion d’erreurs.

Objectif : développer des applications web modernes et robustes.
```

---

### 📕 cours/expert/
```markdown
- Niveau Expert
   - Patterns avancés, optimisation, architecture, sécurité, tests automatisés.

Objectif : maîtriser JavaScript au niveau professionnel.
```
