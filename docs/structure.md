Structure du Projet — JAVASCRIPT-Learning

Le projet est organisé en plusieurs niveaux d’apprentissage regroupés dans le dossier cours/.

Arborescence principale

```text
JAVASCRIPT-Learning/
│
├── README.md
├── LICENSE
│
└── cours/
    ├── debutant/
    ├── intermediaire/
    ├── avance/
    └── expert/
```

Description des niveaux

débutant/
Bases du langage : variables, types, opérateurs, conditions, boucles.

intermediaire/
Fonctions, tableaux, objets, DOM, événements.

avance/
Asynchronisme, API, modules ES, gestion d’erreurs.

expert/
Patterns, optimisation, architecture, sécurité, tests.

Dossier docs/
Contient toute la documentation technique et pédagogique.

```text
docs/
├── introduction.md
├── structure.md
├── guide_pedagogique.md
├── architecture.md
├── securite.md
├── optimisation.md
├── tests.md
├── changelog.md
└── roadmap.md
```

Cette structure garantit une progression claire et professionnelle.
`
