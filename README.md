### 🌐 Présentation

JAVASCRIPT‑Learning est un programme complet, structuré et évolutif pour apprendre le langage JavaScript du niveau débutant jusqu’au niveau expert professionnel.


- Le projet est conçu pour :

```text
- un apprentissage progressif,  
- une documentation claire,  
- des cours modernes,  
- des exercices et projets réels,  
- une montée en compétence militaire‑tech / Quantum‑Era.
```

>Tous les cours sont regroupés dans le dossier :  

```md
cours/
```

---

### 🧭 Niveaux d’apprentissage

>🟢 Débutant
- Bases du langage, variables, types, opérateurs, conditions, boucles.

>🔵 Intermédiaire
- Fonctions, tableaux, objets, DOM, interactions utilisateur.

>🟣 Avancé
- Asynchronisme, API, modules ES, gestion d’erreurs.

>🔴 Expert
- Patterns, optimisation, architecture, sécurité, tests automatisés.

---

### 📁 Structure du projet

```markdown
- cours/debutant/        — Bases du langage
- cours/intermediaire/   — Logique, DOM, fonctions
- cours/avance/          — Asynchronisme, API, modules
- cours/expert/          — Patterns, optimisation, architecture
```
