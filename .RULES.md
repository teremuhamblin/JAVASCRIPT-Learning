📜📜 Règles de Bonne Conduite
- Projet JAVASCRIPT-Learning

Bienvenue dans le projet JAVASCRIPT-Learning.  
Pour garantir un environnement d’apprentissage agréable, efficace et respectueux, merci de respecter les règles suivantes.

---

🧭 Généralités

- Éviter le style SMS  
  → Des messages clairs facilitent les réponses et l’apprentissage.

- Ne pas poster plusieurs fois le même message  
  → Les doublons perturbent la lecture et agacent les autres utilisateurs.

- Ne pas contacter directement les développeurs pour une demande de support  
  → Sauf si cela a été explicitement demandé dans un contexte pédagogique.

- Respecter les sujets de discussion  
  → Toujours donner un titre explicite à vos messages ou issues GitHub.

- Ne pas ajouter des “Urgent”, “Au secours”, “!!!!”  
  → Cela ne vous rendra pas prioritaire.

- Pas de messages commerciaux  
  → Le projet est éducatif, pas un espace publicitaire.

- Pas d’insultes ni de langage grossier  
  → Votre enseignant, vos camarades… ou votre maman pourraient vous lire.

- Aucun propos raciste, fasciste, homophobe ou diffamatoire  
  → Tolérance zéro. Le projet est ouvert à tous.

---

🛠️ Utilisation du projet JAVASCRIPT-Learning

- Rechercher avant de poser une question  
  → Utiliser Google, la documentation du projet, ou les fichiers du dossier docs/.

- Consulter la documentation officielle  
  → Disponible dans docs/ (structure, architecture, sécurité, optimisation, etc.).

- Une seule question par sujet / issue  
  → Pour garder une organisation claire.

- Pas de doublons ni de “Up” répétitifs  
  → Les mainteneurs voient tout, inutile de spammer.

- Si vous avez résolu votre problème, documentez la solution  
  → Cela aide les autres apprenants.

- Passer vos sujets en [résolu] lorsqu’ils le sont  
  → Bonne pratique essentielle pour un projet éducatif.

- Utiliser les citations avec modération  
  → Inutile de citer l’intégralité du message précédent.

---

🎓 Règles spécifiques à l’apprentissage JavaScript

- Tester votre code dans un environnement réel  
  → Navigateur, Node.js, console, sandbox.

- Toujours commenter votre code  
  → Cela aide les autres apprenants et les enseignants.

- Respecter la progression des niveaux  
  → Débutant → Intermédiaire → Avancé → Expert.

- Ne pas sauter les exercices  
  → Ils sont essentiels pour assimiler les concepts.

- Ne pas modifier les fichiers du projet sans raison pédagogique  
  → Sauf dans vos propres dossiers ou forks.

---

🛡️ Respect du cadre pédagogique

Le projet JAVASCRIPT-Learning est conçu pour :
- apprendre,
- progresser,
- partager,
- collaborer,
- s’améliorer.

Merci de contribuer à un espace respectueux, constructif, et motivé.

---

✔️ Merci de faire partie de JAVASCRIPT-Learning.
